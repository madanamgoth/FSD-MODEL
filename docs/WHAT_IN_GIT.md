# What to put in GitHub vs what stays on disk

## Commit / push (code)

| Include | Why |
|---------|-----|
| `src/` | Python scripts (normalize, ingest, generate, approve, status, unlearn, db) |
| `docs/` | SETUP_OCI.md, this file |
| `scripts/` | `env.sh` |
| `requirements.txt` | Python packages |
| `config.properties` | Windows relative defaults |
| `config.properties.example` | OCI absolute `/mmoneyhome/...` paths |
| `.gitignore` | Keeps bulky/generated files out |
| `README.md` | How to run |
| `data/fsds/FSD/PATTERNS/*.md` | Small Mermaid teaching examples |
| `data/sample_brief_sms.txt` | Sample brief |
| `data/**/.gitkeep` | Empty folder placeholders |

## Do NOT commit (copy / generate on server)

| Exclude | Why |
|---------|-----|
| `data/fsds/FSD/FSD-BASE/**/*.docx` | ~100+ real FSDs — bulky + proprietary |
| `data/fsds/FSD/FSD-WORD-DOCUMENT/**` | Same |
| `data/normalized/` | Model X output (regenerated) |
| `data/index/` | Chroma DB (regenerated by ingest) |
| `data/output/` | Model Y drafts |
| `data/app.db` / `*.db` | SQLite tracker (created on first run) |
| `.venv/` | Recreate with `python3 -m venv` |

## How data moves

```text
Windows:  C:\FSD MODEL\data\fsds\FSD\*.docx
    scp/rsync (not git)
Server:   /mmoneyhome/mobiquity/fsd-data/fsds/FSD\

GitHub:   https://github.com/madanamgoth/FSD-MODEL.git
          code only → git clone → /mmoneyhome/mobiquity/fsd-model/
```
